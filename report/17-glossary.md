# Glossary

- **Access control:** Rules determining which identity may perform an action on a resource; enforcement belongs on the server.
- **Authentication:** Establishing who a user or service is.
- **Authorization:** Determining what an authenticated identity may do.
- **CSP (Content Security Policy):** Browser policy that can restrict script and resource behavior as defense in depth.
- **DOM:** The browser's in-memory representation of a web page.
- **DOM-based XSS:** Script injection caused by client-side code placing untrusted data into an unsafe DOM context.
- **JWT (JSON Web Token):** A compact token format. Payloads are usually readable; signing provides integrity, not confidentiality.
- **Loopback:** The local host interface (`127.0.0.1` or `localhost`), reachable only on the same computer unless separately forwarded.
- **Parameterized query:** A database query keeping query structure separate from user-supplied values.
- **Reflected input:** User-provided data returned in the immediate response or rendered page.
- **SQL injection:** A flaw in which untrusted input changes the structure or meaning of a database query.
- **XSS (Cross-Site Scripting):** Injection of attacker-controlled script or markup into a page viewed in a browser.
