# OWASP Top 10 context

The assessment introduces the OWASP Top 10:2021 as a risk-awareness taxonomy. The ten categories below provide context; this test did not assess every category, and category inclusion is not a finding by itself.

| ID | Category | Plain-language description |
|---|---|---|
| A01 | Broken Access Control | Users can act outside their intended permissions. |
| A02 | Cryptographic Failures | Sensitive data is inadequately protected in storage or transit. |
| A03 | Injection | Untrusted data is interpreted as commands or executable content. |
| A04 | Insecure Design | Security requirements or abuse cases are missing from the design. |
| A05 | Security Misconfiguration | Unsafe defaults, excessive exposure, or improper settings weaken the system. |
| A06 | Vulnerable and Outdated Components | Dependencies contain known or unaddressed weaknesses. |
| A07 | Identification and Authentication Failures | Authentication or session controls allow identity compromise. |
| A08 | Software and Data Integrity Failures | Untrusted updates or serialized data are not checked for integrity. |
| A09 | Security Logging and Monitoring Failures | Insufficient monitoring delays detection and response. |
| A10 | Server-Side Request Forgery | An application can be induced to make unintended server-side requests. |

This assessment's findings concentrate on A01, A02, A03, A05, and A07. For current definitions and updated categories, consult the [OWASP Top 10 project](https://owasp.org/www-project-top-ten/).
